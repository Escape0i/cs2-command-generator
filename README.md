## 项目简介

《CS2 指令生成器》把繁琐的控制台指令封装成**可视化模块**。不需要背指令语法，勾选模块、填好参数，就能得到一段完整可执行的复合指令，整段粘贴进控制台即可生效。适用于练习房、单人训练与自建服务器场景。

纯单文件 HTML 实现，零依赖、零构建、离线可用，也可以打包为便携版 exe。

| 10 个一键模板 | 练枪房、5v5 人机、投掷物练习、预瞄、连跳、拆包等高频场景 |

## 快速开始

**方式一：直接打开（推荐）**

1. 下载 `index.html`，用任意现代浏览器打开
2. 顶部可切换配色与界面语言；左侧勾选模块、调整参数，或点模板卡片一键载入
3. 右侧生成指令，点「复制」或「⬇ .cfg」
4. 游戏内按 `~` 打开控制台，`Ctrl + V` 粘贴回车

**方式二：便携版 exe**

从 Releases 下载 `CS2-Command-Generator-<version>.exe`，双击即用，无需安装任何运行环境。

## 使用说明

### 基础流程

```
选择模板 / 勾选模块 → 设置参数 → 复制或导出指令 → 游戏控制台粘贴执行
```

### 配色主题

右上角色点可切换 6 套配色，默认「青夜·高对比」。卡片呼吸光晕、按钮渐变、背景网格等特效全部跟随所选主题变色，选择会被记住。

### 语言与偏好

点右上角「EN / 中文」即时切换中英文，已勾选的模块与参数原样保留。语言、主题、热身归零开关都会被记住，下次打开保持上次状态。

### 血量设置（重点说明）

本工具的「设置血量」模块做了精准的目标区分，避免出现「只想改自己，结果人机也跟着变肉」的情况：

| 模式 | 作用对象 | 实现方式 |
| --- | --- | --- |
| 固定血量 | 只改自己 / 准星瞄准的人机 / 全体 | `ent_fire` 实体指令精准指定目标 |
| 锁血 | 仅自己 | `buddha 1`（客户端命令，天然只作用于自己） |

例：只把自己血量设为 1000（不影响任何人机）

```
sv_cheats 1;ent_fire !self addoutput "health 1000"
```

### 按键绑定（一键出刀）

1. 勾选「按键绑定 · 一键出刀」，设置按键（默认 `p`）与刀型
2. 复制指令执行一次，绑定完成
3. 之后按 P，脚下即生成指定刀具，走过去拾取
4. 取消绑定用「解除按键绑定」模块生成 `unbind p`

### 投掷物练习

- **一键重投上一次投掷物**：`sv_rethrow_last_grenade`，烟、闪、火、雷通用，轨迹与参数完全一致，练 lineup 不必来回跑位
- **一键清除投掷物**：绑一个键，按下清空地图上所有烟雾、燃烧、闪光与手雷
- **轨迹预览窗**：角落显示投掷物落点预览

### 快捷操作

| 操作 | 说明 |
| --- | --- |
| `Ctrl + E` | 复制当前生成的指令 |
| 搜索框 | 按模块名 / 描述过滤，`Esc` 清空 |
| 点击分类标题 | 折叠或展开该分类 |
| 点击模块卡片 | 勾选或取消（参数区点击不会误触） |
| 「⬇ .cfg」 | 导出为 `practice.cfg`，可放入 CS2 配置目录用 `exec` 加载 |

## 重要注意事项

1. **作弊模式前提**：所有生成指令以 `sv_cheats 1` 为前提，仅在自建练习房 / 单人模式生效；官方匹配、竞技模式中无效。
2. **作用域区分**：`mp_` / `sv_` / `bot_` 开头的是**服务器变量**，由房主执行且对全房间生效；`cl_` / `god` / `noclip` 等是**客户端命令**，只影响你自己。想只改自己时请用客户端命令或 `ent_fire !self`。
3. **CS2 的刀不能用 give**：`give weapon_knife_*` 是 CS:GO 遗留语法，CS2 已失效。刀具用 `subclass_create <id>` 生成后拾取（515 蝴蝶刀 / 507 爪子刀 / 508 M9 / 514 Bowie / 525 骷髅刀）。
4. **练习模式无限训练时间**：练习对局默认停在无限训练（热身）阶段，用「结束训练时间」模块或执行 `mp_warmup_end` 立即进入正式回合。
5. **多人房间限制**：`sv_cheats` 只有房主能开启。经实测，好友作为客户端无法自行执行出刀指令，因此本工具**未提供**好友端出刀方案。替代做法：房主执行出刀指令把刀生成在地上，好友走过去拾取即可。
6. **血量指令的目标控制**：固定血量依赖 `ent_fire ... addoutput "health N"`，请在练习房实测确认生效；锁血（`buddha 1`）为客户端命令，只作用于自己。
7. **指令时效**：部分指令（如拾取的刀具）在回合重置后可能失效，需重新生成。

## 本地构建 exe

项目支持通过 Electron 打包为 Windows 单文件 exe（内置 Chromium，目标机器无需安装任何运行时）。

前置要求：Node.js 18+

```bash
npm install
npm run dist
```

产物：`dist/CS2-Command-Generator-<version>.exe`
