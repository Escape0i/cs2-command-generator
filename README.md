## 项目简介

《CS2 指令生成器》面向 CS2 自建练习房与单人练枪场景，将繁琐的控制台指令封装为**可视化模块**。用户无需记忆指令语法，通过勾选模块、填写参数，即可获得一段完整、可执行的复合指令，整段粘贴进游戏控制台即可生效。

核心价值：

- **零门槛**：不懂指令也能搭建 5v5 高难度人机练习房
- **可组合**：17 个指令模块自由搭配，覆盖人机、武器、玩家属性、训练辅助等场景
- **可定制**：每个模块提供独立参数（阵营、数量、难度、血量、武器类型等）
- **即拷即用**：生成结果实时预览，一键复制，支持一行紧凑 / 分行两种视图

纯单文件 HTML 实现，零依赖、零构建、离线可用，双击即可运行。

## 功能特性

| 特性 | 说明 |
| --- | --- |
| 模块化生成 | 17 个指令模块，按「人机对局 / 对局规则 / 玩家增强 / 武器 / 训练辅助」五大类组织 |
| 一键模板 | 内置 3 个高频场景模板：CT 5v5 高难度人机、血量 1000 + 蝴蝶刀、1v5 人机训练 |
| 按键绑定 | 支持将「一键出刀」绑定到任意按键（如 `bind p "subclass_create 515"`），按下即生成蝴蝶刀 |
| 实时预览 | 勾选即生成，一行紧凑 / 分行预览双模式切换 |
| 指令速查表 | 内置常用指令词典，随时查阅每条指令的作用 |
| 单文件部署 | 一个 HTML 文件承载全部功能，支持直接运行或打包为 exe |

## 快速开始

**方式一：直接打开（推荐）**

1. 下载 `index.html`，使用任意现代浏览器打开
2. 左侧勾选模块、调整参数；或点击顶部模板卡片一键载入
3. 右侧自动生成指令，点击「复制指令」
4. 游戏内按 `~` 打开控制台，`Ctrl + V` 粘贴并回车

**方式二：打包为 exe**

参见 [本地构建 exe](#本地构建-exe)，可生成无需浏览器的单文件可执行程序，便于分发。

## 使用说明

### 基础流程

```
选择模板 / 勾选模块 → 设置参数 → 复制生成的指令 → 游戏控制台粘贴执行
```

### 模板速览

| 模板 | 效果 |
| --- | --- |
| 🛡️ CT 5v5 · 高难度人机 | 我方 CT 满编 5 人 vs 敌方 T 5 人，难度 5，冻结 3 秒 |
| ❤️ 血量 1000 + 蝴蝶刀 | buddha 锁血方案设血量 1000，并生成蝴蝶刀展示 |
| 🎯 1v5 人机训练 | 我方 CT 一人 vs 敌方 T 五人，高难度残局练习 |

### 按键绑定（一键出刀）

1. 勾选「按键绑定 · 一键出刀」模块，设置按键（默认 `p`）与刀型
2. 复制生成的指令（含 `sv_cheats 1; mp_drop_knife_enable true; bind p "subclass_create 515"`）粘贴执行一次
3. 之后按 P 键，脚下即生成指定刀具，走过去拾取
4. 不需要时勾选「解除按键绑定」模块生成 `unbind p` 取消

## 重要注意事项

1. **作弊模式前提**：所有生成指令均以 `sv_cheats 1` 开启作弊为前提，仅在**自建练习房 / 单人模式**生效；官方匹配、竞技模式中 `sv_cheats` 被禁用，指令全部无效。
2. **CS2 刀不能使用 give**：`give weapon_knife_butterfly` 为 CS:GO 遗留语法，CS2 原生已失效。刀具必须使用 `subclass_create <id>` 生成实体后拾取，或 `subclass_change <id>` 改型。常用 ID：515 蝴蝶刀、507 爪子刀、508 M9、514 Bowie、525 骷髅刀。
3. **绑定出刀前提**：按键绑定前必须同时开启 `sv_cheats 1` 与 `mp_drop_knife_enable true`。
4. **改血量正解**：`buddha_reset_hp <血量>` 为设置血量的核心指令，配合 `buddha 1`（开启锁血）与 `buddha 0`（关闭）使用。
5. **指令时效**：部分指令（如拾取的刀具）在回合重置后可能失效，需重新生成。

## 本地构建 exe

项目支持通过 Electron 打包为 Windows 单文件 exe（内置 Chromium，目标机器无需安装任何运行时）。

前置要求：Node.js 18+

```bash
# 1. 安装依赖
npm install

# 2. 打包为便携版单 exe（输出至 dist/）
npm run dist
```

产物：`dist/CS2-Command-Generator-<version>.exe`
